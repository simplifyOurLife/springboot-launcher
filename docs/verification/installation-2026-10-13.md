# 独立入口、安装与升级验证记录

日期：2026-10-13。候选版本：0.2.0；本记录不表示正式 Release 已发布。

## 已执行

- 更新元数据、缓存、失败降级、CLI 及更新 HTTP 接口共 6 项定向 Node 测试通过。接口拒绝未认证请求，以及网页指定任意安装路径、脚本或下载地址。
- 停止命令使用临时 HTTP 后台验证：等后台清理并关闭后才返回成功，避免升级复用退出中的实例。
- PowerShell 7 与 Windows PowerShell 5.1 均完成隔离安装流程：中文空格目录、无快捷方式时从安装根直接打开、校验失败保护旧版本、停止失败保护旧版本、版本切换保留旧目录、目录边界与压缩包穿越拒绝。首次安装遇到共享后台忙碌时也不提交新版本。
- 模拟命令向 stderr 输出警告、退出码为零时继续；退出码非零仍阻止切换。已在两个 PowerShell 版本验证，避免普通 npm 警告使安装中断。
- 安装流程以假下载、假 Node/npm 和模拟进程验证，没有真实执行工程编译或自动修改本机客户端配置。
- 浏览器使用三个模拟服务验收。左上角显示 v0.2.0；模拟 v0.3.0 的正式发行信息出现更新标记与说明。此版本仅用于界面演示，不是线上真实发行版。
- 浮动通知出现和自动关闭前后，工作区上边距均为 64px、高度均为 656px；消息采用 fixed 定位，不挤动日志区域。
- npm 包白名单 dry-run 检查、脚本解析与变更空白检查通过。候选 ZIP 已按正式工作流的目录结构整理，不含 node_modules、本机状态或凭据。

## 尚未完成

- 真实机器的首次便携 Node.js 下载、npm 网络准备、不同代理与企业网络环境。

## 本机加载

首次核对时保持业务服务运行；随后使用者明确选择停止服务并加载新版、暂不发布。已停止原托管服务并重启启动器后台，浏览器确认 v0.2.0，项目与分组仍保留，目前没有活跃托管服务。

通过新版页面实际创建桌面 Spring Boot Launcher 快捷方式，确认文件存在且指向固定 PowerShell 面板入口；页面显示创建成功。没有提交、推送或发布 Release。
