# 1.0.0 发布验证

本记录区分本地定向验证、线上 CI 和真实安装，未执行项不写成已通过。

## 发布前已执行

- 19 项 Node 定向验证通过：服务恢复及校时保护、更新检查与来源限制、认证更新接口、停止交接、日志提示关闭、服务排序及发行清单。
- 远端此前失败的 Windows Maven 模拟进程链用例单独通过；只将该链的启动等待从 5 秒调整为 15 秒，不改变断言和实际服务超时。
- Windows PowerShell 5.1 与 PowerShell 7 隔离安装验证通过：中文空格目录、活跃服务保护、校验失败、版本切换、旧版本保留、目录边界、压缩包穿越拒绝；准备目录限定目标根下本次随机子目录。
- 快捷方式源码版和托管安装版通过实际 Shell 读取与执行验证，图标、中文／特殊字符与目录尾随分隔符可用。
- 独立只读审阅发现两项 Important 问题，修复后复核通过：系统校时导致的保护误清理，以及跨卷提交中途失败的半成品风险。
- 本地未执行真实 Java、Maven 或前端构建，未重复全量回归。
- 公开材料使用 1.0.0 当前页面与隔离演示数据重新截图，文档和官网共用图源；不包含维护者真实服务截图。
- 198 个公开候选文件已检查常见凭据与公司／本机用户名路径；16 个历史提交亦无这些模式命中。全部历史 author／committer 为个人身份。此检查不替代全面秘密审计。
- 首次线上验证发现旧跨后台遗留保护用例使用不存在的假 PID，与新增自动清理行为冲突；改为真实存活测试进程，保留原断言并补充进程未被终止验证。
- 云端 Windows Server 2025 的 Node 和两版 PowerShell 安装验证通过，但 Shell 读取 .lnk 的最终外观与 Win11 实机结果不同。服务器显式验证原生 ICO、缓存哈希、路径索引和实际入口执行；Win11 默认测试仍验证 .lnk 合成图标。云端结果不代表已验证最终桌面外观。

## 发布后核对

同一提交的 Windows CI、Pages 部署、Release 资产、在线 SHA-256 与隔离实际安装结果在执行后补充。发布前无法把尚未存在的发行资产写成已验证。

## 未覆盖

全新无 Node Windows 环境的便携运行时真实下载、不同企业代理、真实 WinForms 人工点击、客户端自动注册及真实 Codex／Claude Code 交叉操作，仍需按[人工验收表](alpha-acceptance.md)执行。测试不代表完成独立安全审计，也不证明支持 Gradle、远程管理或其他操作系统。
