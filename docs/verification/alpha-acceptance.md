## 自动准备专项

只在允许编译和下载的可信测试工程执行。先保留可恢复的测试状态，不需要为了验收删除真实业务工程的 target 或本机 Maven 缓存。

| 检查 | 预期 | 结果 |
| --- | --- | --- |
| 缺少／过期产物 | 普通启动进入准备阶段，Maven 日志可见，成功后启动 Java；准备中停止不会继续启动 Java | 待执行 |
| 多模块依赖 | 选择实际应用模块；从根 reactor 准备声明依赖，基础模块不出现在服务列表 | 待执行 |
| 缓存与网络 | 默认离线；明确缓存缺失时自动联网一次。MCP 显式 mvnOffline:true 时不切换，noBuild:true 时不执行 Maven | 待执行 |
