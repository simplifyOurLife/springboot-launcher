# 项目栏布局定向验证

侧栏默认 320px，桌面端边缘分隔条可调至 280–480px，并为主区域保留空间。小屏使用原有移动布局；日志专注视图和独立折叠继续隐藏项目栏。

隔离面板采用临时工程与 Node 模拟输出，没有执行真实 Java、Maven 或前端构建。

- 停止状态只显示启动与按需移除；运行状态显示停止、重启，移除不可用。
- 服务名称独占首行，状态圆点和 Profile 位于第二行，操作不再压缩服务名称。
- 方向键把宽度从 320 调至 336px，刷新后保持 336px；实际拖动分隔条后变为 380px。
- 模块语法及补丁空白检查通过；没有运行全量回归。

宽度记忆按当前面板来源保存，端口变化使用独立浏览器存储。正式后台存在运行中的业务服务，本轮没有中断它，更新在下次正常重开后台后生效。
