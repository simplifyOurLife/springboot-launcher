## 实际浏览器验证

通过隔离后台和真实 Node 子进程产生模拟日志，未运行 Java、Maven 或业务代码。测试夹具为 orders-api、inventory-worker、auth-service；截图和日志明确标注为演示数据。

| 检查 | 观察结果 |
| --- | --- |
| 服务操作 | 启动、停止、重启成功，PID 随重启变化；停止后显示“已停止”和启动入口 |
| 项目切换 | 项目搜索、数量和状态正常；重复添加已有项目不增加条目 |
| 设置草稿 | 修改 Profile 后切换项目再返回，当前页面保留输入；不承诺刷新持久化 |
| 错误反馈 | 非法路径、不可读取目录在添加表单显示错误，修改输入后清除；没有启动业务代码 |
| 日志暂停 | 显示文本保持冻结，后台缓冲容量仍从 16.5 KiB 增加到 22.2 KiB；恢复后显示最新输出 |
| 搜索与复制 | HTML 关键词匹配正常，复制与当前筛选输出相同且不含行号 |
| 输出安全 | `<b>…</b>` 按纯文本显示，日志区域未生成 b 或 script 元素 |
| 自动换行 | 开关对应 `pre-wrap`／`pre`，原始日志字符不变 |
| 跟随 | 关闭后出现“回到最新输出”，点击恢复跟随 |
| 专注与键盘 | 可展开日志专注视图，Esc 退出；非编辑状态下 `/` 聚焦日志搜索 |
| 空项目 | 显示添加项目引导，按钮打开表单并聚焦目录输入 |
| 窄屏 | 430px、320px 宽度无页面横向溢出；菜单选择项目后收起，430px 下设置字段完整显示 |
| 桌面布局 | 默认窗口、1024×768 布局正常；桌面交付截图为当时默认的 1263×1204 视口 |
| 控制台 | 验收期间未观察到浏览器 error／warn 日志 |

对已显示的文字做了颜色对比度检查，并调整辅助文字颜色。已检查的默认、1024px、430px、320px 视图未发现低于 4.5:1 的小字号可见文字；禁用控件和 SVG 不在该文字检查范围内。这不是完整 WCAG 审计，也没有执行 Lighthouse 或 Core Web Vitals 测量。

较早日志超出快照范围时，面板仍显示缺口提示。截图保留该真实提示，不通过移除安全反馈改善画面。

```powershell

node .\tests\helpers\panel-preview.mjs
# 独立的空项目预览
node .\tests\helpers\panel-preview.mjs --empty
```

命令输出一个含短期票据的本机 URL，应及时在浏览器打开。临时会话与控制凭据保存在仓库忽略目录 `.superpowers/panel-preview/`，不要公开分享或提交。预览用于界面验收，不连接实际业务工程。
