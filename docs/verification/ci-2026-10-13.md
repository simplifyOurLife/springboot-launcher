# 首次 GitHub CI 失败定位

运行记录：https://github.com/simplifyOurLife/springboot-launcher/actions/runs/38337624218

依赖安装成功，118 项测试中 116 项通过、2 项失败；后续打包检查因测试失败被跳过。

## 原因与修复

- 并发启动测试通过注入 `spawn` 计数。Windows 停止服务会通过同一接口调用 `taskkill`，辅助进程被误算为服务启动；修复后仅统计模拟服务使用的 Node 可执行文件。
- 停止失败测试覆盖 `child.kill()`，但 Windows 执行器实际使用 `taskkill`，没有注入预期的失败；改为覆盖管理器依赖的 `executor.stop()`，并在 `finally` 中恢复，确保测试清理仍能停止假服务。
- 不修改产品停止逻辑，不跳过测试或降低并发与重启保护断言。

## 验证范围

正常 Windows 权限下，修改前的两个定向测试复现出与 CI 相同的断言错误。修改后执行 `node --test tests/services.test.mjs`，8 项服务生命周期测试全部通过；使用隔离 Node 假服务，不执行真实 Java、Maven 或构建。本地未执行全量回归，云端结果以对应后续 Actions 运行记录为准。

原运行中的 Actions Node.js 20 弃用提示属于警告，checkout 和 setup-node 均成功，不是本次失败原因。
