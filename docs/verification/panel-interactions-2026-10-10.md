# 日志检索与文件夹分组验证

日期：2026-10-10；基于 0.1.0-alpha.1 的未发布修改。本轮只改造日志检索和左侧项目管理，沿用原生 HTML／CSS／ESM 与本机后台。没有执行 Java、Maven 或前端构建。

## 实现行为

- 检索保留连续日志上下文；命中行用浅淡底色，关键词单独高亮，当前位置加强显示。按每处关键词计数，同一行内的多处命中也分别导航。
- 支持上一处／下一处、Enter／Shift+Enter 循环定位。无匹配时保留原日志并显示 0／0。
- 聚焦检索框时固定当前显示，暂停自动滚动，后台继续接收。Esc 或关闭按钮退出检索，更新日志并恢复进入前的跟随选择。
- 显示窗口最多 1200 行；导航到较早匹配时带出对应连续上下文。密集关键词最多同时挂载 3000 处高亮，当前命中始终保留，全部匹配仍可导航。复制当前连续显示窗口，不带行号和高亮标记。
- 左侧提供单层逻辑文件夹，可创建、改名、展开／收起、导入项目和移动项目；移除文件夹时项目回到未分组，不修改磁盘工程。
- 点击加号由本机后台打开 Windows 目录选择窗口。应用模块直接导入，项目根目录扫描其中的 Maven Boot 模块；取消不修改工作区，重复导入不增加重复记录，导入不启动服务。
- 分组与导入记录在用户私有目录的 workspace.json 中原子保存；变更串行提交，失败回滚，多个面板通过 SSE 同步。
