# 面板视觉与交互设计

本次调整于 2026-10-10 按 [taste-skill](https://github.com/Leonxlnx/taste-skill) 及其 [redesign-existing-projects](https://github.com/Leonxlnx/taste-skill/tree/main/skills/redesign-skill) 指导完成。主技能偏展示网站，本面板采用配套重构技能适用的原生 CSS 流程，不套用营销页图片、滚动动画或框架迁移要求。

## 设计方向

面向本地 Java 开发者的日常服务工作台。使用者已选择“浅色工作台＋深色日志区”。保留绿色品牌色和现有品牌标识，浅色区域负责项目与操作，深色区域专门呈现程序输出。

设计参数为 DESIGN_VARIANCE 3、MOTION_INTENSITY 2、VISUAL_DENSITY 7：位置可预测，反馈克制，优先扩大日志的可用空间。使用项目自己的语义色和组件，不宣称是 Fluent、Primer 或其他官方设计系统实现。

## 实现约束

- 沿用 HTML、原生 CSS 和 ESM，没有新增构建步骤；后台使用锁定的 YAML 解析依赖读取 Profile 元数据。
- 保留八个 MCP 工具、会话兑换、同源限制、SSE 和后台状态权威。
- 原运行设置字段 ID、顺序和参数含义保持一致；项目导入替换原手工目录表单。设置草稿只保存在当前页面内，刷新后不保留；重启仍沿用后台记录的上次启动请求。
- 未显式设置端口时显示“采用应用配置”，不推断应用实际监听状态。应用就绪依据仍由后台提供。
- 系统字体优先使用 Windows 的 Segoe UI Variable、微软雅黑和 Cascadia Code，中文不依赖外部字体网络请求。
- 图标使用 Phosphor 官方资源并内嵌为本地符号，完整许可证随源码分发。保留原有 favicon 与品牌标识。
- 日志每次最多呈现 1200 行连续上下文；检索覆盖当前固定缓冲的每处关键词，窗口随定位覆盖较早命中，不删除无匹配行。密集关键词每个窗口最多挂载 3000 处高亮，当前命中保证高亮，仍可定位全部匹配，并明确提示限制。
- 聚焦检索框时固定当前显示，关闭并禁用自动跟随，后台继续接收。检索期间不因实时输出重建日志 DOM；退出后更新为最新缓冲并恢复此前的跟随选择。普通暂停仍保留原有语义。
- 命中行采用浅淡底色，关键词用 mark 文本节点显示，当前关键词有更强底色和描边。Enter／Shift+Enter 或箭头按钮循环前后定位，计数以每处关键词为单位，同一行多处分别定位。
- 复制当前连续显示窗口，不包含行号或高亮标记。所有输出、分组名称和项目名称通过文本节点呈现，不使用 HTML 插值。
- Esc 优先退出检索，再次按下可退出专注视图；非编辑状态下按 `/` 聚焦日志检索。提供跳过导航链接、可见焦点、原生表单标签和减少动态效果支持。
- 项目目录通过后台的固定 STA PowerShell 脚本调用 Windows FolderBrowserDialog 选择，不上传工程文件，也不要求网页取得整个磁盘的访问权。取消选择不导入；单个后台同时只允许一个选择窗口。
- 左侧文件夹为单层逻辑分组，可创建、改名、展开／收起、导入和移动项目；移除文件夹只将项目放回未分组。工作区记录在当前用户私有目录的 workspace.json 中原子保存，操作串行提交，保存失败不改变内存状态；其他面板通过 SSE 同步。
- 断线重连、日志缺口、写盘失败及恢复提示继续使用既有状态约定。

## 样式与资源

绿色强调色为 `#0e7564`；浅色页面、项目侧栏、表单、深色输出区域分别使用统一的语义色。圆角以小控件约 6px、日志组容器 10px 为主，品牌标识保留自身形状。过渡仅用于交互反馈，减少动态效果设置下禁用。

Phosphor Icons 来源修订为 `2b75f3ad12b420c9504ef05df8d2564a28f8500e`，只内嵌所需的 regular 图标，不修改路径数据。来源和 MIT 许可见[第三方说明](../../THIRD_PARTY_NOTICES.md)与[原始许可证](../../web/licenses/phosphor-icons.txt)。

## 服务管理补充（2026-10-10）

- 服务图标为自绘 Spring Boot 风格六边形电源图形；状态用 9px 圆点表示，悬停及读屏保留状态名，侧栏不重复显示状态文字。第二行优先显示运行记录的 Profile，其次显示已识别的项目配置值，悬停区分来源；识别不到时标为“应用配置”，不使用编辑草稿冒充运行值。
- 服务右侧常驻启动、停止、重启三个图标按钮，按后台状态禁用；操作作用于该行，重启沿用上次参数。移除项目管理菜单，使用内部指针拖拽及 Ctrl+Shift+M／Enter 键盘移动，拖动不影响磁盘路径。
- 后台按 stdout／stderr 独立流式解析 ANSI，只传纯文本与受限样式元数据；16 色、256 色、RGB 和基本字形用安全文本节点显示。检索时固定文本与颜色快照，关键词高亮优先；文件和复制保持纯文本。颜色元数据计入后台缓存与快照大小限制，前端最多保存 2000 段颜色范围。
- 不同后台使用独立 Cookie 名称；会话失效关闭 SSE 重试并显示可复制的打开命令。新票据支持在已有页面中兑换，不削弱认证或来源校验。

## 运行环境与空间补充（2026-10-10）

- Profile 下拉枚举本地标准配置文件、文档条件与分组。自动值就近显示来源；未解析占位符或外部配置显示提示。自动模式不向 Java 添加覆盖参数，用户主动选择才覆盖；运行日志可更新实际 Profile。
- JDK 下拉显示路径、版本、来源和不兼容原因，排除低版本和缺少 javac 的候选；默认带入推荐版本。自定义目录作为兼容入口，“重新识别”保留手动选择。扫描不执行候选程序，启动仍验证 Java 版本。
- 顶部只保留服务标题、操作和一行摘要；设置默认收起，常用四字段与高级 jar／classpath／JVM 参数分开折叠。桌面 1280×720 下日志容器约 487px 高。
- 服务行三按钮按启动绿、停止红、重启蓝显示，并保留文字提示和禁用态，颜色不是唯一操作依据。窄屏允许自然换行，不引入横向页面滚动。
