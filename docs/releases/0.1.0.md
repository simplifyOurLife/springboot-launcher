# Spring Boot 启动器 0.1.0

首个基础版本：版本号与 package.json 一致，对应源码标签 `v0.1.0`。本说明不表示已创建 GitHub Release 或完成全部验收；实际验证范围见下文。

在 Codex 或 Claude Code 中管理本地 Maven Spring Boot 服务，在同一网页查看实时日志。后台按需启动，聊天结束后服务仍可继续运行，无需为了启停和看日志打开 IDEA。

## 本次提供

- 每轮启动重置内存日志缓冲，磁盘历史继续保留；日志缺口提示可手动关闭，本轮后续输出与重连不会反复显示。
- 改善编译产物判定与容器 classpath：忽略全注释 Java 文件，按实际类内容保留必要 JSP 依赖，优先加载容器 API。
- 默认英文 README 与独立中文 README；面板支持中英文切换，保留当前配置草稿和原始业务日志。
- 单服务可从启动器移除，刷新后保持移除结果；磁盘工程与日志保留，活跃和异常遗留进程受到保护。
- 共用本机后台的八个 MCP 工具：发现、检查、启动、状态、日志、停止、重启和打开面板。
- Windows 系统目录选择、应用模块扫描、逻辑文件夹与拖拽管理；基础库不会仅因继承 Spring Boot 就列为服务，旧导入记录也会重新检查。
- 从 application 配置识别 Profile，扫描本机 JDK，并提供下拉选择和来源提示。
- 优先使用可运行的已有产物；缺少或过期时，普通启动自动准备 Maven 编译和依赖，过程与应用日志在同一面板显示。
- 启动缺类时受限修复一次；默认离线准备遇到明确缓存缺失时自动联网重试一次。显式固定离线或 noBuild 时遵循对应限制，业务错误不会无限重建。
- 彩色日志、连续上下文检索、命中行与关键词高亮、上一处／下一处定位；检索时停止自动滚动，后台继续收集。
- 启停按钮即时反馈，停止阶段持续收集输出；项目栏与顶部信息独立折叠，收起后保留当前服务名。
- 本机认证、短期面板票据、有界日志与异常遗留记录保护。

## 安装与使用

安装说明见[README](../../README.md)，接入说明见[Codex](../usage/codex.md)和[Claude Code](../usage/claude-code.md)。本次按源码安装；没有发布 npm 包、客户端市场扩展或独立安装程序。

环境基线为 Windows 11、PowerShell 7、Node.js 22.22.2 或更新的兼容版本，以及目标工程需要的 JDK。自动准备还需 Maven Wrapper，或可通过 MAVEN_HOME、M2_HOME、PATH 找到的本机 Maven。

升级已有安装时，先停止托管服务，执行 `node .\bin\springboot-launcher.mjs daemon stop`，更新源码及依赖，再执行 `node .\bin\springboot-launcher.mjs dashboard`。面板端口可能改变，请使用新链接。后续版本更换提交的具体方式由实际仓库地址和发行版本确定。

## 支持范围与已知限制

| 范围 | 当前限制 |
| --- | --- |
| 平台与构建 | 仅以 Windows 本机 Maven 工程为当前目标；Gradle、其他系统、远程管理与固定客户端侧栏不在本次验收范围 |
| 复杂工程 | 本地 POM 分析不等于 Maven effective POM；自定义构建 Profile、插件输出和依赖冲突可能需要手动配置 |
| Profile 与 JDK | Profile 扫描不能完整复现远程配置、占位符或 IDE 参数；JDK 发现不遍历全盘，支持手动指定可信目录 |
| 停止 | Windows 先非强制停止，最多等待 8 秒后再强制结束；不保证 JVM 关闭钩子执行，也不能恢复应用未输出的停止日志 |
| 异常恢复 | 后台异常后不自动接管旧 JVM；遗留记录需人工核验，不能依历史 PID 盲目终止进程 |
| 页面与日志 | 折叠和设置草稿仅保留在当前页面；日志有容量限制，检索不等于查询全部历史磁盘日志 |
| 验收 | 真实 Java、单模块与嵌套 Maven 自动准备、实际 Codex／CC 交叉操作和 GitHub CI 尚无完整通过记录 |

当前已有自动检查、模拟子进程和浏览器验证；这些证据不能替代真实服务验收。历史证据见[验证映射](../../documentation/tests.md)，最近修复见[验证补充](../verification/alpha-followups.md)，待执行项目见[简短验收表](../verification/alpha-acceptance.md)。
