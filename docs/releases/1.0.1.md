# Spring Boot Launcher 1.0.1

修复 1.0.0 在线安装校验文件解析问题，推荐新安装和升级使用本版本。保留 1.0.0 标签与发行资产，不移动已公开版本。

## 修复

GitHub 将 checksums.txt 作为 application/octet-stream 返回，PowerShell 的 Content 为 byte[]。1.0.0 安装器按字符串解析，导致安装包实际完整仍提示 SHA-256 校验失败。

现在先按严格 UTF-8 解码，兼容文本响应、二进制响应与 UTF-8 BOM，再按原规则核对文件名和 SHA-256。官方 Node.js 校验文件也使用相同处理；校验失败仍会中止安装，不绕过完整性检查。

## 安装

从 [官网](https://simplifyOurLife.github.io/springboot-launcher/#get-started) 下载安装引导，或下载本 Release 的 install.cmd 后双击，选择安装位置。**从 1.0.0 升级时须重新下载最新引导并选择原安装目录，1.0.0 内置升级向导也包含旧解析逻辑。** 1.0.1 后可继续使用左上角升级入口。已运行服务默认阻止切换，只有明确勾选才停止。

本版继续面向 Windows 本机 Maven Spring Boot。完整功能说明见 [1.0.0](https://github.com/simplifyOurLife/springboot-launcher/releases/tag/v1.0.0)，本版验证见[在线安装验证记录](https://github.com/simplifyOurLife/springboot-launcher/blob/main/docs/verification/release-1.0.1.md)。安装脚本没有代码签名，未发布 npm 公共包。
