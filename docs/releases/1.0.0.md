# Spring Boot Launcher 1.0.0

在线安装入口的校验文件解析问题已在 [1.0.1](https://github.com/simplifyOurLife/springboot-launcher/releases/tag/v1.0.1) 修复；新安装推荐使用该补丁版本，1.0.0 标签保留。

首个 1.0 正式版本，面向 Windows 本机 Maven Spring Boot 开发。可通过桌面入口独立打开服务管理面板，也可通过 Codex／Claude Code 共用同一个后台。安装向导提供目录选择、快捷方式与可选 MCP 接入，无需手工替换安装路径。

## 新增与改进

- 左上角显示版本号，后台缓存检查正式 GitHub Release；更新可打开独立向导。
- Windows 安装向导可选择目录、快捷方式和客户端接入。需要时下载官方便携 Node.js，并校验 SHA-256；运行依赖按锁文件安装，不运行 Java 或工程构建。
- 托管安装使用独立版本目录与稳定入口，升级不需要重新修改 MCP 路径。下载、校验、依赖准备完成后才切换版本；旧版本保留。
- 升级遇到运行中的托管服务会阻止切换；只有使用者在向导中明确勾选后才停止服务。源码工作树不被原地覆盖。
- 顶部消息改为浮动提示、自动消失和悬停暂停，显示与关闭不改变日志区高度。
- 服务拖动排序持久化，启动另一项时切换选择与日志；默认 Profile 标签、站内移除确认和启动参数布局更新。
- 日志范围、检索状态及告警提示均可关闭，同轮后续输出不反复显示。
- 修复关机后旧服务一直显示“需要人工确认”：后台自动清理已退出或能确认系统已重启的登记；校时不会解除存活进程保护，证据不足时仍保守保留。
- 修复桌面入口路径与白色图标问题，安装准备改为目标盘随机暂存目录，避免跨盘失败留下半成品影响重试。

## 安装与升级

从 [官网](https://simplifyOurLife.github.io/springboot-launcher/) 下载在线安装引导，或下载本 Release 的 `install.cmd` 后双击。向导下载本版本发行包并核对 `checksums.txt`，不需要 Git 或管理员权限；首次安装需要访问 GitHub、npm，缺少 Node.js 时还需访问 nodejs.org。

源码用户可双击根目录 `Open Dashboard.cmd`。在左上角版本窗口点击“创建桌面快捷方式”可添加本地打开入口。托管安装用户通过“打开升级向导”升级；服务停止后需由用户自行重新启动。

## 验证与范围

针对安装路径、校验失败、停止失败、版本切换、服务恢复、更新元数据与消息提示进行定向验证，并完成独立代码复核。线上 CI 与真实下载安装结果在[本版本验证记录](../verification/release-1.0.0.md)中单独记录；全新机器与真实客户端自动接入仍需验收。自动流程不构建真实 Java 工程。支持范围为 Windows 本机 Maven Spring Boot，复杂构建与不同网络代理可能需要额外配置。

安装脚本尚无代码签名；本项目没有 npm 公共包，也不是 Spring、Codex 或 Claude Code 的官方产品。许可证与代码来源见仓库相关文件。
