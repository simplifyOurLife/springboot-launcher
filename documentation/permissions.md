# 权限边界

## 当前状态与身份来源

当前已有认证、精确 Host、浏览器同源、私有 ACL 与托管进程检查；拒绝路径证据见[验证记录](../docs/verification/mvp.md)。这不代表独立安全审计。

系统只面向当前 Windows 用户，没有多用户角色。代理身份来自当前用户私有目录中的随机后台控制凭据，网页身份来自单次票据兑换的会话；业务 JVM 运行权限来自该操作系统用户。

| 资源／操作 | 持有有效控制凭据的本地代理 | 有效网页会话 | 未认证／跨站访问 |
| --- | --- | --- | --- |
| 检查和发现项目 | 允许受限检查 | 允许受限检查 | 拒绝 |
| 托管服务状态与日志 | 允许，输出受限 | 允许，流及缓冲受限 | 拒绝 |
| 启动可信项目 | 参数校验与项目互斥后允许 | 参数校验与项目互斥后允许 | 拒绝 |
| 停止／重启当前托管 JVM | 所有权核验后允许 | 所有权核验后允许 | 拒绝 |
| 操作未知进程／异常后的旧 PID | 拒绝 | 拒绝 | 拒绝 |
| 获取面板单次票据 | 允许 | 无需长期凭据 | 拒绝 |
| 读取长期控制凭据 | 仅私有目录本地读取 | 拒绝发送给网页 | 拒绝 |
| 任意 shell／文件／公网代理 | 不提供 | 不提供 | 不提供 |

同一用户配置的代理拥有同一组托管服务权限，MVP 不提供按客户端分区。客户端可额外对工具调用审批，但服务器必须独立执行认证、参数校验及进程所有权检查。

本项目不使用数据库或行级安全策略。目录权限由 Windows ACL 实际核验；不能将路径位于 LOCALAPPDATA 当作已证明权限正确。浏览器与代理的鉴权不能因回环来源而省略。
