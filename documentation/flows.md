# 受保护的操作流程

## 连接与后台

MCP 代理或 CLI 检查私有目录 ACL，经独占锁创建隐藏后台，读取实例文件并核对随机实例身份、控制凭据和健康响应。连接不启动业务 JVM。存活但不可达的锁拥有者不会被替换，代理退出不停止后台。

实例回收、创建、拥有者交接及发布在同一跨进程临界区执行，记录完整后原子发布，避免空锁与删除新一代锁。交接锁拥有者意外退出时保守拒绝自动回收，需人工检查。

## 服务启动

后台校验控制凭据／网页会话、Host 和浏览器来源，再校验参数、规范化目录、取得项目锁，检查产物、JDK、端口。产物可用时使用原生可执行文件与参数数组启动 Java；缺少或过期时，普通启动托管 Maven 编译及依赖准备，立即返回准备状态并持续收集日志。准备成功后重新检查再启动；失败保留诊断。noBuild:true 时直接返回 BUILD_REQUIRED。导入和检查不执行 Maven。

后台拥有子进程句柄，记录状态、有限恢复元数据和日志。进程存活与就绪分离，端口开放只是 TCP 证据，不意味着应用健康。客户端都读取同一注册表。

仅显式 port 才覆盖 Spring 端口。显式 healthUrl 只允许无凭据的本机 HTTP，限制超时和读取容量，持续确认健康；DOWN、401 或超时保持未确认，不能被启动日志覆盖。

## 面板与日志

面板从 fragment 取短期单次票据，立即移除 fragment，经同源兑换取得 HttpOnly、SameSite=Strict 会话。后续状态、操作、SSE 校验会话和来源。日志按 UTF-8 增量解码并以纯文本显示；快照、事件队列、内存、磁盘和 MCP 片段均有上限，缺失片段提示缺口。

日志是应用输出，不作为指令执行。主动 MCP 查询的片段会进入 AI 会话；没有后台自动上传。

单个实时事件分块，日志对象数量与序列化容量同时受限。SSE 快照最多 64 KiB，重连使用 Last-Event-ID；裁剪即提示缺口。写盘失败主动推送警告并持续显示，修复后重新启动恢复。

## 停止、重启与异常记录

只停止当前后台托管子进程，Windows 准备阶段停止整棵 Maven 进程树，不按端口或旧 PID 杀进程。等待 close 和尾部日志后记录终态，准备与 Java 启动之间收到停止也不会继续启动。重启先确认停止成功，再重新检查并按需准备产物；失败不启动第二进程。

点击停止先在页面显示等待提示和对应服务行加载状态；后台进入 stopping，但日志订阅保持连接。Windows Java 阶段先调用不带 /F 的 taskkill /T，最多等待 8 秒，仍未退出再强制停止。等待 close 与输出排空后关闭本次日志并提交终态；不能把发送停止请求当作已停止，也不保证每个 JVM 能执行关闭钩子。

后台启动先核对旧服务登记：已确认退出的 PID、系统运行时长明确回退、能确认已重启的记录会自动清理；项目分组和历史日志保留，服务恢复为可手动启动的已停止状态。存活、无有效 PID 或探测失败的旧记录保留 orphaned，拒绝自动接管、停止或重复启动。使用者人工处理这些服务后，可通过带确认参数的 CLI 遗忘记录。正常关闭后台默认拒绝仍有服务，明确停止全部时才执行停止。

## 升级与旧工作区校正

使用者先停止托管服务并正常关闭后台，更新源码和依赖，再打开面板。页面资源随新后台启动载入，旧端口不作为持久登录地址。

新后台建立服务注册表后，复核已导入工程；只将 inspect 明确判定 matched=false 且未运行／无待确认遗留状态的记录从逻辑工作区移除，持久化成功才发布新状态。无法读取的工程保留。此操作不删除磁盘工程，也不执行 Maven 或 Java 服务。
