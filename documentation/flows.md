# 受保护的操作流程

以下均为预期流程，当前没有对应产品实现或已通过的验证。

## 连接与首次启动后台

参与者是本机已配置 MCP 的 Codex／CC 或本地命令。代理读取当前用户的私有实例文件；若后台不存在，则经原子锁创建一个隐藏后台并验证实例身份与凭据。

文件创建、锁和后台进程属于实际本地副作用，但连接本身不能启动业务 JVM。错误凭据、伪造实例、尚存但无响应的锁拥有者或目录权限不正确时应停止连接，不能回退到无认证或并行创建第二后台。

代理退出只关闭连接。后台带运行服务退出时须拒绝，并要求先停止服务或明确选择全部停止。

## 业务服务启动

参与者是已认证的 MCP 代理、本地命令或网页会话。浏览器到后台、代理到后台是独立信任边界；必须先校验会话／控制凭据及 Host，浏览器还须符合精确同源要求。

随后校验项目和参数、规范化目录、取得项目互斥锁、检查产物／JDK／端口、直接启动 Java。缺少产物、目录无法确认、参数非法、端口占用或已运行时应返回明确结果，不进行隐式构建、shell 执行或未知进程终止。

副作用是创建托管 JVM、记录有限元数据、写入本地日志并向已认证连接推送状态。对启动结果的健康描述必须有实际证据，不能把端口开放当作完整健康检查。

## 打开面板与读取日志

代理请求短期单次面板票据，页面从 fragment 取得票据并交换 HttpOnly 会话。兑换校验票据、有效期、单次使用和同源来源；失败时不给状态、日志或操作权限。

后续状态请求及 SSE 均检查会话，返回有限快照及有序事件。应用输出跨越 JVM→后台→浏览器边界，必须以 UTF-8 增量解码及纯文本处理，不能执行日志中的 HTML。

MCP 日志读取需控制凭据和已托管项目标识，结果大小受限。返回的片段会进入用户当前 AI 会话；后台不能主动外发其他日志。

## 停止、重启与异常记录

认证后确认目标属于当前后台，并只使用保存的托管子进程句柄。已退出时返回终态；非托管目标和旧后台遗留记录拒绝自动终止。

停止会改变 JVM 和状态；尾部输出读取结束后再关闭日志文件。重启必须确认停止成功，再重新检查产物及配置。停止失败时不创建第二 JVM。

后台异常退出后的记录只用于诊断。未经人工确认不能依旧 PID 接管或重复启动；旧记录不等于已恢复进程所有权。
