Full installation guide ↗

Prefer a guided installation?

Download and open the Windows installer. Choose a folder, create desktop shortcuts, and optionally connect Codex or Claude Code.

Download installerRequires an internet connection. The guide can install a portable Node.js runtime if needed.

1Install & open

Run in PowerShell from the folder where you want to keep the source.

PowerShell
git clone https://github.com/simplifyOurLife/springboot-launcher.git
cd springboot-launcher
npm ci --ignore-scripts --no-audit --no-fund
node .\bin\springboot-launcher.mjs dashboard

The backend starts on demand and opens an authenticated local dashboard. Import a trusted project to get started.

2Connect your AI client

From the same source folder, run the command for your installed client. Reopen the client afterward.

PowerShell
$launcher = (Resolve-Path .\bin\springboot-launcher.mjs).Path
codex mcp add springboot-launcher -- node $launcher mcp

The Claude Code command uses user scope, making this MCP available across your projects.

3Ask for what you need

“Inspect D:\demo\orders-service, start it with the local profile on port 8087, and open its live log dashboard.”

Missing artifacts may trigger Maven compilation and dependency downloads. Run only projects you trust.

A few things to know.

Can this website control my services?

This is the public project website. The application runs on your computer and opens its own authenticated dashboard. Start it with the dashboard command above.

Do I need to keep a terminal open?

No. The backend starts on demand. Closing the launching terminal or an AI chat does not stop the managed services. Use the dashboard or CLI to stop them.

Which projects and platforms are supported?

The current target is local Maven Spring Boot development on Windows. Gradle, macOS, Linux, and remote management are outside the current acceptance scope. Complex build configurations may require manual setup.

Is this an official Spring or AI client product?

It is an independent open-source project under Apache-2.0, with no official affiliation to Spring Boot, Codex, or Claude Code. Source attribution and current limitations are documented in the repository.
